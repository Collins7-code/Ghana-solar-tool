# 🤝 Contributing to Ghana Solar Tool

First off — thank you. This project is built in the open, by people who believe
Ghana's energy future should be built by Ghanaians (and friends). Whether you
fix a typo or add a whole module, you're welcome here.

## 🌍 Why this exists
Ghana has some of the strongest sunshine on earth, yet solar supplies only
~1–3% of grid electricity. The gap isn't desire — it's guesswork. This tool
sizes a home solar system, estimates the cost in cedis, and shows the payback,
so families can decide with confidence.

## 🧑🏾‍ Who can contribute
- **Coders** — Streamlit/Python improvements
- **Data people** — real tariffs, irradiance, installer prices
- **Translators** — Twi, Ga, Ewe, Hausa, French
- **Installers & engineers** — sanity-check the physics and prices
- **Designers** — make it beautiful and mobile-friendly

## 🚀 How to contribute
1. **Fork** the repo.
2. Create a branch: `git checkout -b fix/short-description`
3. Make your change. Keep it small and commented.
4. Run it: `pip install -r requirements.txt && streamlit run app.py`
5. **Commit** with a clear message and **open a Pull Request**.
6. Describe what + why. Screenshots for UI changes = ❤️

## 🐛 Found a bug?
Open an **Issue**: what you expected, what happened, your region, screenshot.

## 💡 New feature idea?
Check open Issues first (look for `good first issue` / `help wanted`).
For a brand-new idea, open an Issue *before* building so we can talk it through.

## 🧠 Ground rules
- Be kind. People here are learning — including the founder (he's 17 😄).
- Document your assumptions. An honest estimate beats a fake-precise number.
- Cite your data sources (Energy Commission, GSS, GHA…).
